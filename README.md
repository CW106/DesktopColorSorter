# 桌面顏色整理器 (DesktopColorSorter)

一個 Windows 11 桌面客製化工具：依顏色排列桌面圖示、用圖示排出圖案並加上動畫、自訂開始功能表、工作列背景照片、個人化色彩和滑鼠游標。

單一 `.exe`，不需要安裝，使用 Windows 內建的 .NET Framework 4.x。

## 功能

| 分頁 | 功能 |
|---|---|
| 顏色排列 | 分析每個桌面圖示的主色，依彩虹順序（紅→橙→黃→綠→青→藍→紫→粉→黑白灰）排列；可選直欄 / 橫列、每個色系另起一欄，隨時可以還原 |
| 像素圖案 | 用桌面圖示排出愛心、星星、笑臉、文字或照片（照片會依顏色挑最接近的圖示）；動畫：隨機跳動、互相換位、波浪，形狀維持不變 |
| 個人化色彩 | 淺色 / 深色模式、透明效果、強調色（Windows 色盤、自訂顏色或取自桌面圖示的主色） |
| 工作列 | 工作列背景照片（半透明、滑鼠可穿透、可框選位置、全螢幕時自動隱藏）；對齊方式、搜尋、工作檢視、時鐘秒數、自動隱藏 |
| 開始功能表 | 仿 Windows 11 開始功能表：搜尋、已釘選、建議、全部（類別 / 格線 / 清單）；毛玻璃或照片背景、開關動畫；Windows 鍵、開始按鈕、Ctrl+Esc 都會開啟它 |
| 滑鼠游標 | 套用 Windows 內建游標配置，或產生自訂顏色 / 彩虹漸層的游標（會先備份原本的游標） |

另外：一鍵隱藏 / 顯示全部桌面圖示（`Ctrl+Alt+H`），可縮到通知區域、開機自動執行。

## 執行

到 [Releases](../../releases) 下載 `DesktopColorSorter.exe`，雙擊執行。

## 自己編譯

需要 Windows 10 / 11（內建 .NET Framework 4.x 的 `csc.exe`），雙擊：

```bat
build.bat
```

會在同一個資料夾產生 `DesktopColorSorter.exe`。程式碼只用 C# 5 語法，所以可以用 Windows 內建的編譯器。

| 檔案 | 內容 |
|---|---|
| `Core.cs` | 桌面圖示存取（IFolderView）、顏色分析、顏色排列、像素圖案、圖示讀取 |
| `PatternAnimator.cs` | 桌面圖示動畫（跳動 / 換位 / 波浪） |
| `Personalize.cs` | 個人化色彩、工作列設定與背景照片、滑鼠游標 |
| `StartMenu.cs` | Windows 鍵 / 開始按鈕攔截、應用程式清單 |
| `StartPanel.cs` | 自訂開始功能表視窗（繪圖、動畫、搜尋） |
| `CropDialog.cs` | 照片框選視窗 |
| `MainForm.cs` | 主視窗與程式進入點 |

## 注意事項

- 設定、背景照片、游標備份存在 `%LOCALAPPDATA%\DesktopColorSorter`。
- 「小工具」等部分工作列設定受 Windows 的保護機制（UCPD）限制，其他程式無法修改。
- 工作列的部分設定在 Windows 11 25H2 要重新啟動檔案總管才會生效（程式裡有「立即套用」按鈕）。
- 工作列照片是疊在工作列上方的半透明視窗；打開 Windows 原本的搜尋時，Windows 會把工作列移到比所有程式都高的一層，那段時間照片會被蓋住。
- 開始功能表的應用程式分類是依名稱判斷的，和 Windows 自己的分類不一定相同。
